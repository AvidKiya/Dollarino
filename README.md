# Dollarino (دلارینو V11.7.2) — پلتفرم جامع و غیرامانی ترید هوشمند ۵-موتوره، اکستنشن پنل کناری ساده Chrome، Trust Wallet DApp (EVM + Solana)، استودیو کارت سود و ربات تلگرام

**Dollarino (دلارینو)** یک وب‌اپلیکیشن معاملاتی، PWA قابل نصب، اکستنشن کروم با **پنل کناری بومی (`chrome.sidePanel` v11.7.2)** و سامانه اتوترید چندارزی و آن‌چین مبتنی بر **Cloudflare Workers + D1 + Durable Objects + React 18** و **ربات تلگرام ۲۴/۷ (`@Dollarino_bot`)** است که به‌صورت **۱۰۰٪ غیرامانی** بر بستر **Trust Wallet DApp** (در شبکه‌های EVM، Solana، TON و TRON) و **Perp DEX** فعالیت می‌کند.

> **بنیان‌گذار و معمار نرم‌افزار:** آوید کیا (`Avid Kiya`) · تلگرام: `@avidkiya`  
> **مستندات کامل V1.0 تا V11.7.2:** [`DOLLARINO-COMPLETE-DOCUMENTATION.md`](./DOLLARINO-COMPLETE-DOCUMENTATION.md)  
> **گزارش راستی‌آزمایی زنده (Desktop/Mobile/SidePanel × Light/Dark):** [`QA-VERIFICATION-REPORT.md`](./QA-VERIFICATION-REPORT.md)

- **ثبت خودکار کد معرف مدیر + ثبت‌نام مستقیم DApps تراست‌ولت + فرم یکپارچه پروفایل:**
  - هر کاربر جدیدی که بدون وارد کردن کد معرف (از کیف‌پول، گوگل، تلگرام یا ایمیل) ثبت‌نام کند، به‌صورت خودکار زیرمجموعه کد معرف مدیر ثبت می‌شود.
  - دکمه ثبت‌نام کیف‌پول سایت را مستقیماً در مرورگر DApps تراست‌ولت برای ثبت‌نام/امضا باز می‌کند و پس از ورود با **کیف‌پول، گوگل یا تلگرام** فرم تکمیل مشخصات (**شماره تماس، اسم مستعار، نام کاربری و رمز عبور**) نمایش داده می‌شود.

- **ثبت خودکار موتور هنگام استارت ربات + شارژ سولانا خزانه + TP/SL درصدی (V11.7.1):**
  - ذخیره قطعی موتور فعال (`STRATEGY` / `CENTRAL_AI` / ...) هنگام کلیک روی «شروع ربات» حتی از وضعیت پیش‌فرض `[]` در D1 + راهنمای خطای عدم همگام‌سازی Worker روی Cloudflare Pages.
  - افزودن شبکه **Solana (`SOL / USDC · Jupiter`)** به بخش «شارژ سریع خزانه ۲۴/۷ و مجوز محدود روتر DEX» (تولید تراکنش آماده امضای `SystemProgram::Transfer` در `/api/trustwallet/build-solana-fund-tx` + دیپ‌لینک `coin=501` و لینک مستقیم Jupiter بدون نیاز به Approve روتر).
  - پشتیبانی کامل از حالت **`درصد (%)` در کنار `قیمت ($)`** برای تنظیم SL و TP1/TP2/TP3 همراه با محاسبه لحظه‌ای قیمت دقیق، دکمه‌های درصد آماده و پیش‌نمایش اهرمی `ROE %` در پایانه معامله، ویرایش پوزیشن‌ها، Perp DEX و پنل ادمین.

- **تنظیمات پیش‌فرض کاملاً ایمن (All-OFF) و مرکز تنظیمات یکپارچه (`0046`):**
  - حساب‌های جدید با امنیت کامل (`bot_state='STOPPED'`، تمامی ۵ موتور خاموش `[]`، تایید دستی، اعلانات خاموش و اسنایپر خاموش) ساخته می‌شوند تا کاربر دقیقاً بخش‌های دلخواه خود را فعال کند.
  - امکان تغییر واحد نمایش (`USD` / `تومان`) و ۵ سوییچ دقیق اعلان‌ها (همگام بین سایت و تلگرام).
- **استودیو کارت سود یکپارچه (Perp + DEX + Copy · `16:9` و `9:16` Story):**
  - پشتیبانی از ۸ بازه (`24H`, `7D`, `30D`, `3M`, `6M`, `1Y`, `ALL`, و کارت تک‌معامله `TRADE` با آیکون کوین، قیمت ورود/خروج، منبع سیگنال و QR تایید) در ابعاد واقعی **`1200×675` (`16:9`)** و **`1080×1920` (`9:16`)**.
- **معماری ۱۰۰٪ غیرامانی سرمایه شخصی (`Zero Custody`):**
  - تمام سرمایه معاملاتی کاربران همیشه داخل **کیف‌پول Trust Wallet شخصی خودشان** باقی می‌ماند و هیچ سرمایه تریدی به سایت واریز نمی‌شود.
  - مدیریت بودجه ربات مستقیماً با **سقف مجاز سرمایه روی ولت شخصی** (`$50–$1000`، درصدی یا کل ولت) و با ولت ۲۴/۷ اختصاصی با کلید خصوصی در اختیار خود کاربر (`AES-256-GCM`) انجام می‌شود.
- **۰٪ اشتراک ماهانه · کارمزد فقط ۳٪ از سود واقعی لایو:**
  - تمامی ابزارها، کدنویسی Pine/Python، چت هوشمند، رادارها و شبیه‌ساز دمو قابل تنظیم (**`$50` تا `$10,000,000`**) برای همه رایگان است.
  - **۳ معامله سودده اول در حالت لایو کاملاً رایگان (`۰٪`)** و پس از آن فقط **۳٪ کارمزد سرور از سود خالص معاملات موفق** محاسبه و با Trust Wallet تسویه می‌شود (`۹۷٪` سود برای کاربر).
- **اجرای همزمان ۵ موتور معاملاتی رسمی (در وب و تلگرام):**
  1. **هوش مصنوعی مرکزی دلارینو (`CENTRAL_AI`):** اجماع چندمدلی روی Hilinkup / DeepSeek / Claude / GPT / Gemini با فالبک بدون‌قطعی `dollarino-live-ai`.
  2. **استراتژی منتخب دُرنا V1 (`DOLLARINO_V01` / `KBOs`):** اسکن خودکار کل بازار (۸۰۰+ فیوچرز و ۱۰۰۰+ اسپات) با ۳ تارگت، Break-Even و Trailing SL.
  3. **هوش مصنوعی شخصی من (`MY_AI`):** آموزش استراتژی شخصی با چت فارسی + محیط کدنویسی بدون `eval` برای **Pine Script v4/v5** و **Python Quant**.
  4. **کپی‌ترید حرفه‌ای (`Smart Copy V2`):** رصد Top-10 نهنگ‌های آن‌چین + کپی‌ولت ۲۴/۷ با کلید در اختیار کاربر.
  5. **اسنایپر لیستینگ و میم‌کوین (`SNIPER`):** رصد لحظه‌ای توکن‌های جدید در Solana/BSC/Base با فیلتر نقدینگی و نمره ایمنی ضدراگ.
- **یکپارچه‌سازی واقعی و امن Trust Wallet In-App DApp Browser:**
  - احراز مالکیت رمزنگاری واقعی `personal_sign` (`secp256k1 ecrecover`) با Nonce یک‌بارمصرف ۵ دقیقه‌ای در D1 (`0042`).
  - ویزارد ۱-کلیکی **Hyperliquid EIP-712 `ApproveAgent`** (فقط-معامله با صفر دسترسی برداشت)، سوآپ آن‌چین مستقیم (`/api/dex/build-swap-tx` با Jupiter v6 و ParaSwap/1inch) و مجوز محدود روتر + `Revoke`.
- **احراز هویت ۳ مسیره، تکمیل پروفایل و امنیت TOTP 2FA (`0044`):**
  - ثبت‌نام و ورود با **Trust Wallet**، **Google** یا **Telegram** (با Phone KYC) + دروازه تکمیل پروفایل + **احراز هویت دوعاملی Google Authenticator (`TOTP RFC 6238`)**.
- **بهینه‌سازی کلادفلر و مرکز فرماندهی مالک (`0041`):**
  - `44` مایگریشن D1 شامل **۵۲ جدول و ۷۱ ایندکس بهینه‌سازی**، کش حافظه‌ای `settings-cache.ts`، کنترل مستقل ارسال سیگنال به کانال‌ها و ربات کاربران، و مدیریت جامع D1 (آمار، Pruning، Backup JSON، Restore و Factory Wipe).
- **PWA بدون کش مزاحم (`v11.6.5`) + اکستنشن کروم MV3 (`v11.6`) + پشتیبانی تصویری AI Vision (`FloatingAiChat`):**
  - سرویس‌ورکر Network-First (`dollarino-pwa-v11.6.5`)، هدرهای `no-store` در `_headers`، و دستیار چت شناور با تحلیل تصویر چارت و صدور ستاپ معامله.

- **سخت‌سازی امنیتی، ضدسوءاستفاده و محدودسازی نرخ (`Rate Limiting` + Security Headers):**
  - محدودیت نرخ دولایه (Isolate Cache + D1) روی ثبت‌نام، ورود، تولید کلید اکستنشن، پرداخت، کد هدیه، برداشت رفرال، اسکن هوشمند AI و سفارش‌های دستی.
  - افزودن هدرهای امنیتی استاندارد روی تمامی مسیرهای `/api/*` و هش‌کردن IP و اثرانگشت مرورگر بدون افشای PII.
- **باشگاه همکاران رفرال چندسطحی + برداشت نقدی USDT (ضد تقلب و ضد فیک):**
  - سطح‌بندی پلکانی واقعی: **برنزی (۱۵٪)**، **نقره‌ای از ۵ خرید موفق (۱۸٪)**، **طلایی از ۱۵ خرید موفق (۲۲٪)** + **۱۰٪ پورسانت تمدیدها** + **۷ روز اشتراک هدیه**.
  - مسدودسازی خودکار دعوت از خود، اکانت‌های تکراری هم‌دستگاه/هم‌IP (`FLAGGED_DUPLICATE`)، هم‌پوشانی شماره تلفن/کیف‌پول و جلوگیری از آزاد شدن پورسانت با کد هدیه رایگان (`$0`).
  - امکان **تبدیل آنی موجودی به اشتراک پرو** (حداقل `$5`) یا **درخواست برداشت نقدی USDT (BEP20 / TRC20)** (حداقل `$10` با الزام احراز شماره تلگرام و تایید/رد با بازگشت وجه خودکار در پنل مدیریت).
- **پایداری ۱۰۰٪ رادار DEX (`DexScreener + GeckoTerminal`) و بازارهای زنده (`OKX/Coinbase Fallback`):**
  - افزودن هدر استاندارد، `Promise.allSettled`، فالبک دوگانه سرور به `GeckoTerminal API v2` و فالبک سمت کلاینت جهت نمایش بی‌نقص توکن‌ها و سوآپ Trust Wallet.
- **بازطراحی ترمینال حرفه‌ای (Pro Terminal) و رفع کامل باگ‌های مودال (`createPortal`):**
  - رفع تداخل CSS `backdrop-filter` در جستجوی ارزها و مودال‌ها، نوار تیکر یکپارچه، ارتفاع هم‌تراز چارت و فرم سفارش، نوار لحظه‌ای فشار خرید/فروش و Workbench پنج‌تب تمام‌عرض.
- **طراحی مجدد اکستنشن مرورگر v9.6 (`Liquid Glass` + ۴ تب + تم روز/شب):**
  - اکستنشن مدرن هم‌طراحی با سایت اصلی، آیکون‌های SVG، ۴ تب (**ربات / بازارها / رادار DEX / اتصال و رفرال**)، بستن پوزیشن، اسکن AI و ساخت/تست کلید با خطایابی واضح.

- **لوگوها و نشانگرهای SVG تمام ارزها، طلا و سهام (`CoinIcon`) + حذف کامل ایموجی‌های UI:**
  - طراحی اختصاصی بیش از ۲۰ لوگوی SVG با زنجیره Fallback 4-CDN + پشتیبانی از عکس واقعی توکن‌های DexScreener (`imageUrl`) و جایگزینی تمام ایموجی‌های کارتی/دکمه‌ای رابط کاربری با آیکون‌های استاندارد Lucide و بنرهای گرافیکی اختصاصی.

  - پاسخگویی آنی دستیار هوش مصنوعی در وب و ربات تلگرام بر پایه وضعیت واقعی حساب، صرافی و اشتراک کاربر — همراه با دکمه ۱-کلیکی «گفتگو مستقیم با مدیران انسانی» و بازگشت به دستیار هوشمند.
- **همگام‌سازی خودکار عکس پروفایل تلگرام (`GET /api/auth/avatar/:userId`):**
  - دریافت خودکار عکس اکانت تلگرام کاربران از Bot API (بدون افشای توکن ربات)، همراه با امکان بارگذاری عکس دلخواه و دکمه بازگشت به عکس تلگرام در بخش تنظیمات.

- **ربات جامع تلگرام (`@Dollarino_bot`) + احراز هویت امن شماره تماس (Phone KYC) + کانال رسمی (`@Dollarino_official`):**

  - پس از احراز: اتصال مستقیم صرافی‌های **Toobit** و **KCEX** + **Trust Wallet DApp** + **حساب شبیه‌ساز**، انتخاب **حالت ساده / حالت حرفه‌ای**، راه‌اندازی ۴ مرحله‌ای (**Wizard**)، تنظیم تعاملی مقادیر معامله (`تنظیم مقادیر معاملات 🪛`)، منوهای تعاملی تاشو، اتوترید و دستی‌ترید با تایید دو مرحله‌ای، **هوش مصنوعی قابل آموزش من**، **کپی‌ترید تاییدشده**، **مدیریت کانال و ارسال خبر**، **پشتیبانی آنلاین یکپارچه** و **پنل مدیریت کامل** (`944021185`).

  - **رادار زنده DexScreener:** شناسایی توکن‌های ترند و داغ غیرمتمرکز که هنوز در Toobit/KCEX لیست نشده‌اند، تحلیل هوشمند AI برای هر توکن DEX، ساخت لینک ۱-کلیکی سوآپ در Trust Wallet DApp و پیگیری پورتفوی معاملات DEX.

  - دانلود مستقیم فایل آماده اکستنشن از صفحه داشبورد (`/downloads/dollarino-extension.zip`) و اتصال با کلید اختصاصی `X-Dollarino-Extension-Key` برای کنترل آنی ربات، Kill Switch و مشاهده تراز و پوزیشن‌ها در نوار مرورگر.
  - پشتیبانی از **ویجت‌های قابل سفارشی‌سازی داشبورد و میانبرهای سریع PWA** (`/?quick=bot-toggle | report | dex | kill-switch`).

## استقرار یکپارچه روی Cloudflare Workers + D1

جزئیات کامل در `DEPLOY-CLOUDFLARE.md` قرار دارد؛ خلاصه گام‌ها:

1. ریپازیتوری را در GitHub قرار دهید و دیتابیس D1 بسازید (و `database_id` را در `wrangler.toml` تنظیم کنید؛ شامل مایگریشن‌های `0001` تا `0018`):
   ```bash
   npx wrangler d1 create dollarino-db
   npx wrangler d1 migrations apply dollarino-db --remote
   ```
2. کلیدهای امنیتی رمزنگاری AES-256، JWT، تلگرام و هوش مصنوعی Hilinkup را در Cloudflare Secrets ثبت کنید:
   ```bash
   openssl rand -base64 32 | npx wrangler secret put MASTER_ENCRYPTION_KEY
   openssl rand -hex 32 | npx wrangler secret put SESSION_JWT_SECRET
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put HILINKUP_API_KEY
   ```
3. بیلد و استقرار یکپارچه فرانت‌اند (`apps/web/dist`) + API را اجرا کنید:
   ```bash
   npm run build && npx wrangler deploy
   ```
4. اولین کاربری که ثبت‌نام می‌کند نقش مالک (`owner`) می‌گیرد و می‌تواند از تب **مدیریت** مدل‌های **هوش مصنوعی دلارینو**، تعرفه پلن‌ها، تریدرهای کپی‌ترید، پشتیبانی آنلاین و واریزی‌ها را مدیریت کند.

> ⚠️ **هشدار امنیتی:** هرگز کلیدهای API هوش مصنوعی، توکن ربات تلگرام (`TELEGRAM_BOT_TOKEN`) یا کلیدهای صرافی را داخل Git قرار ندهید؛ همیشه از Cloudflare Secrets یا بخش رمزنگاری‌شده پنل استفاده کنید.
