# Dollarino (دلارینو v7.1) — هوش مصنوعی دلارینو، استراتژی منتخب، کدنویسی Pine/Python و ربات کامل تلگرام

**Dollarino (دلارینو)** یک وب‌اپلیکیشن تجاری، PWA قابل نصب و سیستم ترید خودکار چندارزی مبتنی بر **Cloudflare Workers + D1 + Durable Objects + React** و **ربات تلگرام ۲۴/۷ (`@Dollarino_bot`)** است که با طراحی سبک iOS / Apple و الهام‌گرفته از اپلیکیشن‌های فین‌تک موبایل، به کاربران اجازه می‌دهد در چند ثانیه و بدون نیاز به دانش پیچیده، به‌صورت همزمان روی تمام ارزهای مناسب بازار معامله کنند.

## ویژگی‌های کلیدی نسخه v7.1

- **ربات جامع تلگرام (`@Dollarino_bot`) + کانال سیگنال رسمی (`@Dollarino_official`):**
  - اتصال مستقیم صرافی‌های **Toobit** و **KCEX** + **Paper Demo** داخل تلگرام با نمایش موجودی (`Free / Used / Total`)، تنظیم تعاملی مقادیر معامله (`تنظیم مقادیر معاملات 🪛`)، حالت اتوترید و دستی‌ترید با تایید دو مرحله‌ای (`👈 دلارینو ترید کن برام 👉` ← `تایید میکنم ✅` / `نه دستم خورد ❌`)، اعلان‌های کامل برد و باخت با تایم ورود/خروج ایران، خرید اشتراک ۴ پلن با TRC20 و کیف پول، و **پنل مدیریت ۹ بخشی کامل** (محدود به مدیر اصلی `944021185` با خروجی اکسل CSV/JSON و تایم‌اوت ۱۵ دقیقه‌ای).
- **ثبت‌نام، ورود و اتصال ۱-کلیکی وب ↔ تلگرام:**
  - ورود و همگام‌سازی فوری بین سایت و ربات تلگرام از طریق لینک مستقیم `t.me/Dollarino_bot?start=LINK-...`، مینی‌اپ بدون نیاز به رمز و لینک جادویی `/weblogin`.

- **حالت ساده (راه‌اندازی ۴ مرحله‌ای هم‌تراز با TimeTrade):**
  - تنها کافیست مبلغ سرمایه را مشخص کنید و در ۴ گام (**۱. مبلغ سرمایه · ۲. سطح ریسک · ۳. استراتژی · ۴. تأیید و شروع**) ربات خودکار ۲۴/۷ را با امکان اتصال مستقیم صرافی واقعی روشن کنید — به همراه نمودار عملکرد ساعتی و تب معاملات باز/تسویه‌شده.
- **حالت حرفه‌ای کوانت + محیط کدنویسی Pine Script v5 و Python (`Pro Quant IDE`):**
  - **اجرای کد TradingView Pine Script و پایتون روی چارت زنده:** پشتیبانی داخلی (بدون `eval`) از اندیکاتورهای `ta.ema`، `ta.sma`، `ta.bb`، `ta.supertrend`، `ta.macd`، `ta.rsi`، دستور `plot()`، `strategy.entry()`، کدهای Pandas-style Python و **استراتژی‌ساز بصری بدون کد (Visual Rule Builder)**، با رسم مستقیم روی کندل‌های چارت، بک‌تستر کامل و فعال‌سازی روی ربات ۲۴/۷.
- **معاملات کامل اسپات (Spot) و فیوچرز (Futures) روی تمام بازار (`ALL_MARKET` / `TOP_COINS` / `SINGLE`):**
  - پشتیبانی همزمان از **بازار اسپات (Spot)** با اهرم اجباری `1x` و محافظت در برابر شورت مارجین، و **بازار فیوچرز (Futures)** تا اهرم `50x` در صرافی **Toobit** و حساب دمو.
  - اسکن چرخشی بدون محدودیت (Uncapped) روی **تمام جفت‌ارزهای فعال بازار (۸۰۰+ فیوچرز و ۱۰۰۰+ اسپات)** با پشتیبانی از تا **۲۰ معامله همزمان**.
  - **تنظیم جهت معامله ربات و Hedge Mode:** انتخاب حالت‌های `BOTH` (لانگ + شورت)، `LONG_ONLY` (فقط خرید)، `SHORT_ONLY` (فقط فروش) و **حالت هج دوطرفه (`hedge_mode`)** برای نگهداری همزمان لانگ و شورت روی یک ارز در فیوچرز.
- **کارت سود تاییدشده رمزنگاری‌شده (Server-Signed Verified Profit Card):**
  - صدور کارت با امضای دیجیتال سرور (`HMAC-SHA256`)، کد QR و صفحه عمومی استعلام اصالت (`/verify-card/:cardId`) همراه با تفکیک شفاف **عملکرد واقعی (Live)** از **حساب آزمایشی (Paper Demo)**.
- **ربات و مینی‌اپ تلگرام یکپارچه:**
  - همگام‌سازی خودکار دستورات `/start`، `/app`، `/positions`، `/balance`، `/settings`، `/help`، دکمه‌های Inline کنترل Spot/Futures/Direction/Hedge و پیوند دوتایی وب ↔ مینی‌اپ تلگرام (`LINK-XXXXXX`).
- **سه موتور رسمی دلارینو:**
  1. **هوش مصنوعی دلارینو (موتور دُرّبین):** ترکیب هوشمند ۱ تا ۳ مدل هوش مصنوعی (DeepSeek، Claude، GPT، Gemini و OpenRouter) توسط مدیریت پلتفرم — بدون نیاز به ثبت کلید API توسط کاربر.
  2. **استراتژی منتخب دلارینو (موتور دُرنا V1):** ترکیب جامع استراتژی‌های روند، مومنتوم، شکار نقدینگی و ریبون غیرریپینت؛ رایگان در حساب دمو برای همه کاربران.
  3. **کپی ترید دلارینو:** کپی خودکار و لحظه‌ای سیگنال‌ها از کانال تلگرام `@Dollarinoofficial` یا کانال اختصاصی کاربر و TradingView Webhook.
- **طراحی لوکس Apple / iOS + دسکتاپ حرفه‌ای (بدون اموجی، کاملاً SVG و آیکون‌های Lucide):**
  - پنل ساده با کارت کیف‌پول کُبالت، نوار شناور پایین موبایل (iOS Dock)، چراغ‌های سبز تیره با خوانایی کامل در تم روز (Light Mode) و دکمه **حالت حرفه‌ای تریدرها (Pro Mode)**.
- **صرافی‌های پشتیبانی‌شده:**
  - **Paper Demo** (حساب دمو رایگان با قیمت زنده بازار) · **Toobit Spot & Futures** · **KCEX (Signal Mirror)**.

## راه‌اندازی لوکال

```bash
npm install
npx wrangler d1 migrations apply dollarino-db --local
npm run dev:worker   # پورت 8787
npm run dev:web      # پورت 5173
```

## استقرار روی Cloudflare + GitHub

1. ریپازیتوری را در GitHub (Private یا Public) قرار دهید.
2. دیتابیس D1 بسازید و `database_id` را در `wrangler.toml` جایگزین کنید:
   ```bash
   npx wrangler d1 create dollarino-db
   npx wrangler d1 migrations apply dollarino-db --remote
   ```
3. کلیدهای امنیتی رمزنگاری AES-256 و JWT را در Cloudflare Secrets ثبت کنید:
   ```bash
   openssl rand -base64 32 | npx wrangler secret put MASTER_ENCRYPTION_KEY
   openssl rand -hex 32 | npx wrangler secret put SESSION_JWT_SECRET
   ```
4. Worker را دیپلوی کنید (`npx wrangler deploy`) و `apps/web` را به **Cloudflare Pages** متصل کنید (`Build command: npm run build`، `Build output directory: apps/web/dist`).
5. اولین کاربری که ثبت‌نام می‌کند نقش مالک (`owner`) می‌گیرد و می‌تواند از تب **مدیریت** مدل‌های **هوش مصنوعی دلارینو**، تعرفه‌ها و واریزی‌ها را مدیریت کند.

> ⚠️ **هشدار امنیتی:** هرگز کلیدهای API هوش مصنوعی، توکن ربات تلگرام (`TELEGRAM_BOT_TOKEN`) یا کلیدهای صرافی را داخل Git قرار ندهید؛ همیشه از Cloudflare Secrets یا بخش رمزنگاری‌شده پنل استفاده کنید.
