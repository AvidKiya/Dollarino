  4. **Missing Platform Features vs Web:**

     - Direct DEX Quick-Buy button on DexScreener trending tokens inside the popup

     - Updated version `11.7.0` + rebuilt `apps/web/public/downloads/dollarino-extension.zip`

### 2. Telegram Bot Audit (`apps/worker/src/telegram/`)
- **Status:** Strong Simple/Pro architecture exists, but misses specific Website parity & Profit Card features.
- **What Already Works:** Per-user `ui_mode` (`'simple' | 'pro'`), `tg_toggle_ui_mode` + reply button toggles, 4-step `showSimpleWizardStep`, `mainMenuKeyboard`, `tg_engines_menu` (5 concurrent engines), `tg_dex_trending`, `tg_copy_smart_v2`, `tg_ai_chat`, `tg_tv_alerts`, `tg_ext_widgets`, `tg_profit_card`.
- **Verified Parity Gaps:**
  1. **Simple Mode Keyboard Parity (`formatter.ts:97–103`):** Simple Mode keyboard omits **کارت سود دلارینو 📊** and **⚙️ تنظیمات سریع و مدل AI** (only present in Pro Mode), whereas Website Simple Mode gives direct access to Model Settings, Strategy Check, My AI, Copy Pros, Sniper, and Profit Cards.
  2. **Profit Card Telegram Menu (`handler.ts:2851,4344`):** Missing **3M (سه ماهه)**, **6M (شیش ماهه)**, and **TRADE (تک‌معامله — picking from user's recent closed Perp/DEX/Copy trades)**, and vertical PNGs render at `1080x1440` (`3:4`) instead of true `9:16` (`1080x1920`).
  3. **New Telegram User Defaults:** Calls `ensureUserDefaults`, which currently inherits `active_engines_json = '["CENTRAL_AI"]'` ON instead of all engines & automation toggles OFF.
  4. **Version Strings (`formatter.ts`):** Still references `V11.6` in welcome text & Chrome Extension button.

### 3. Admin Panel Audit (`apps/web/src/pages/AdminPage.tsx` & `apps/worker/src/routes/admin.ts`)
- **Status:** Comprehensive (`9` sections, ~40 routes), with 4 practical operational improvements worth adding.
- **What Already Exists:** Live System Health & D1 Housekeeping, 1–3 Combined Dorrbin AI Engine Manager, BIP39/Trust Wallet Central Treasury Bank, 3% Fee Debt/Grace/Lock Enforcement, Fee Gift Codes, Referral Withdrawals & Anti-Fraud Queue, Auto Top Copy Traders Discovery, Online Support Inbox, Telegram Bot/Token/Webhook/Channels/Community Group Moderation, Banners, Founder Identity, On-Chain Indexer APIs, Audit Logs, D1 JSON Backup/Restore/Factory Wipe.
- **Verified Gaps:**
  1. **No Issued Profit Cards Audit & Revocation Registry:** Admin cannot view a central list of issued Profit Cards across Perp/DEX/Copy or revoke a fraudulent/compromised card ID.
  2. **3% Fee Invoices Ledger vs Legacy Orders:** Legacy subscription `orders` table takes focus under `payments` instead of a clean filterable 3% Profit Fee Invoices & Settlements table.
  3. **Live Running Bots Inspector & Admin Emergency Stop:** Health panel counts running bots, but lacks a per-user active bots table with 1-click Admin Stop for support emergencies.
  4. **Telegram Admin Menu Parity (`admin-menu.ts`):** Web Admin has Banners, Founder Identity, On-Chain APIs, and D1 Backup/Wipe that aren't mirrored in quick summaries on Telegram Admin.
