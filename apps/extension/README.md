# Dollarino Companion Browser Extension (v9.0)

اکستنشن رسمی دلارینو برای مرورگرهای Chrome، Edge، Brave و Opera:
- کنترل ۱-کلیکی روشن/خاموش کردن ربات تریدر
- دکمه توقف اضطراری (Kill Switch) و بستن سریع پوزیشن‌ها
- نمایش زنده موجودی، سود و ضرر باز و نشانگر عددی روی آیکون مرورگر
- دسترسی مستقیم به رادار **DexScreener** و دکمه‌ی سوآپ **Trust Wallet DApp**

## راهنمای نصب سریع:
1. این فایل ZIP را از حالت فشرده خارج کنید (Extract).
2. در مرورگر Chrome آدرس `chrome://extensions` را باز کرده و **Developer mode** (بالا سمت راست) را روشن کنید.
3. دکمه **Load unpacked** را بزنید و پوشه خارج‌شده را انتخاب کنید.
4. کلید اکستنشن خود (`dlr_ext_...`) را از ربات تلگرام `@Dollarino_bot` یا پنل وب کپی و در اکستنشن وارد کنید.
